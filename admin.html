The signed e-book is a certified, digitally signed PDF uploaded directly (no e-sign workflow on this site). To make signed-copy claims live: host the PDF in S3-compatible storage and set EBOOK_STORAGE_* — each one-time download then gets a fresh, short-lived presigned URL generated at the moment of access. (Or set EBOOK_DOWNLOAD_URL to a private URL.) Then set EBOOK_SIGNED=1. Until then the welcome email honestly offers a free digital copy with no autograph claim.
